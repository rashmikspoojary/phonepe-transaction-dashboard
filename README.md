## PhonePe Transaction Analysis Dashboard | Power BI

An interactive Power BI dashboard built to analyze PhonePe transaction data and transform raw data into meaningful insights through data visualization and reporting.

## Project Overview

This project focuses on exploring digital payment transaction data using Microsoft Power BI. The dashboard helps visualize transaction patterns, identify trends, and present data in an interactive and easy-to-understand format.

## Tools & Technologies

* Microsoft Power BI Desktop
* Power Query
* DAX
* Data Visualization
* Data Cleaning and Transformation

## Key Features

* Interactive transaction analysis
* Visual representation of transaction trends
* KPI cards for key transaction metrics
* Charts and graphs for data exploration
* Interactive filters and slicers
* Data-driven insights through visual reporting
